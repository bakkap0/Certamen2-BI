# Certamen 2 · Inteligencia de Negocios

**Caso 2 · Bike Z · Sección 300**

Construimos una solución para analizar las ventas de Bike Z por fecha, producto,
cliente, vendedor y territorio.

| Fase | Contenido | Estado |
| --- | --- | --- |
| [Fase 1](fase-1/README.md) | Modelo dimensional, scripts SQL, respaldo de `BikeZ_DW`, ETL en SSIS, informe, presentación y evidencias. | Entregada |
| [Fase 2](fase-2/README.md) | Cubo OLAP en SSAS, scripts de validación y dashboard de Power BI conectado al cubo. | Cubo validado en SSAS y dashboard de Power BI con tres páginas. |

Para ejecutar el cubo se usa el `BikeZ_DW` cargado de la Fase 1. El [respaldo y
las instrucciones de restauración](fase-1/database/backup/README.md) están junto
al resto de los entregables de esa fase.
